# 지도 UI 겹침/요약/가독성 수정 계획

작성일: 2026-11-06 · 최종 수정일: 2026-11-06 · 시간 기준: Asia/Seoul

사용자가 캡처에서 확인한3개 문제 수정을 승인했다. 기존 ViewBinding/Material BottomSheet/SDK 지도와 데이터 흐름을 유지한다. 별도 화면이나 의존성은 추가하지 않는다.

- [x] 현재 APK에서 버튼 겹침/요약 가시성 UI 회귀 실패를 확인한다.
- [x] 이전 h720dp 지도 variant를 제거해 단일 지도 배치를 사용한다. 지도 버튼은48dp 가로 행으로 접힌 시트 위에 두고, 전체화면에서는 탐색 막대 위로 이동한다.
- [x] 접힌 높이를 route_summary의 실제 하단+여백+탐색 inset으로 계산해 줄바꿈/내용 변경에 반응한다. 기존 pane은 시트가 없는 배치를 유지한다.
- [x] 툴바에 기존 ui_card 배경을 적용하고 상태바 inset은 카드 밖으로 옮겨 텍스트/버튼이 상태바와 겹치지 않게 한다.
- [x] 단위/lint/APK 및 standard/small/pane UI/캡처로 겹침·요약·전체화면/복귀를 확인한다.
- [x] 검증 해시/새 캡처·로드맵·로그·설치 대상을 갱신한다. 실기기/명세 전체 인수와 구분한다.

가로 버튼 행/실제 높이 기반 peek는 이번 요청을 만족하기 위한 구현 선택이다. 서버·DB·Room·점수·기존 글꼴/세로 고정 정책은 바꾸지 않는다.
