# 상단 카드 최소화

작성일: 2026-11-20 · 최종 수정일: 2026-11-20 · 시간 기준: Asia/Seoul

사용자 승인: 상단 제목/검색 카드에 최소화 버튼 추가. 접으면 오른쪽 위에 작은 사방 대각선 화살표 아이콘만 남고 누르면 복귀. 하단 경로 패널과 독립적으로 동작한다.

1. Smoke 기반 회귀 검사에서 기존 APK의 최소화 버튼 부재를 확인한다.
2. toolbar의 상태 문구 옆에 최소화 버튼, activity_main에 독립 확대 버튼과 vector 아이콘/접근성 설명을 추가한다. 아이콘24dp/터치48dp. MainActivity에서 카드 표시·지도 여백·전체화면 복귀·saved state를 처리한다. 태블릿 기존 고정 레이아웃은 유지한다.
3. 빌드/단위/lint 후 동일 해시 설치, API35 일반/작은 화면 최소화·확대/입력·결과 보존/전체화면 복귀 및 하단 패널 독립성 검사. 로그/ROADMAP 갱신.
