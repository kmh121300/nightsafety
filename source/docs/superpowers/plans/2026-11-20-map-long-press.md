# 지도 길게 누르기 출발·도착 선택

작성일: 2026-11-20 · 최종 수정일: 2026-11-20 · 시간 기준: Asia/Seoul

사용자 승인 범위: 지도 길게 누르기→출발지/도착지 선택→가까운 등록 보행 node로 보정→보정 위치·거리 확인→기존 경로 검색. TMAP과 로컬 미리보기 둘 다 지원한다. 원래 위치까지의 미검증 직선을 경로로 생성하지 않는다.

1. 별도 POST /v1/places/snap API의 필수 좌표 검증·30m 밖 보정·그래프 밖 node 제외·HTTP 동작 회귀를 작성하고 기존 코드 실패를 확인한다.
2. 기존 Engine/HTTP/RouteApi를 확장한다. 기존 compare.anchor의30m 제한과 파일럿 BBOX를 유지한다. 보정 API는 파일럿 내 가장 가까운 활성 graph node를 반환한다. DB/그래프/점수 정책·버전은 바꾸지 않는다.
3. 앱 TMAP long-press 콜백 및 Preview의 GestureDetector/화면 좌표 역변환을 연결한다. 공통 메뉴에서 방향을 고르면 비동기 보정 후 원래점·보정점·거리/미검증 연결 안내를 보여준다. 확인 버튼에서 좌표 입력에 반영하고 기존 search 실행. 새 요청/취소 시 이전 비동기 결과가 반영되지 않도록 기존 revision을 재사용한다. 검색 후 기존 경로 endpoint 핀을 재사용한다.
4. 서버/Android 테스트, 빌드/lint 및 DB snapshot 서버의 실제 API·API35 지도 두 종류 길게 누르기/보정/검색·시설 탭 회귀를 검사한다. 날짜/대상 APK/제약을 로그와 ROADMAP에 기록한다.

선택 제한: 파일럿 밖은 거절, 동일 보행점은 기존0거리 처리, 단절 component는 경로 없음으로 처리. 가장 가까운 node 선택이며 edge 임시 분할/현장 접근성 판정은 이번 범위 밖이다. 실제 원점에서 anchor까지 거리/시간/점수는 경로 수치에 합산하지 않는다.
