# safenight DB integration implementation plan

Created: 2026-10-26 · Last updated: 2026-10-26 · Verification date: 2026-10-26 · Timezone: Asia/Seoul

Task scope: DB persistence and server snapshot/API integration. Checked tasks do not certify the full Android UI. Current whole-project status: [Roadmap](../../../../ROADMAP.md). Latest UI limitation: [verification](../../../verification/database-integration-2026-10-26.md#android-화면-확인).

**Goal:** Import the pilot into the existing safenight schema and serve the unchanged Android API from a database-loaded snapshot.

**Design:** Keep the existing Dijkstra engine and experimental data policy. Persist facilities, all OSM nodes/tags, directed edges, and scoring samples in versioned bundles. Read one complete bundle in a read-only repeatable-read transaction at startup. No per-request database writes or silent fallback. Existing local mode remains available without DATABASE_URL. PostGIS is already installed in extensions. No pgRouting dependency is needed.

**Authorization:** User approved table creation, data import, verification and server integration in this conversation. Do not replace existing data or expose credentials. This directory has no Git repository, so work is performed in place.

**Tech:** Python 3.10+, psycopg3, PostgreSQL/PostGIS, existing Android HTTP contract.

- [x] Implement secret-safe configuration, safenight schema/importer, read-only DB snapshot loading and startup selection. Enable RLS on new tables without granting client access.
- [x] Run local regression tests. Verify failed imports roll back and configured DB errors never fall back to local mode.
- [x] Import into the authorized development schema. Verify counts, geometry validity and SRID, repeated import, and parity with local route results through HTTP.
- [x] Update execution instructions and evidence with actual checks and remaining limitations.

**Ruling:** Use startup snapshots rather than pgRouting or per-request SQL. This preserves the already verified Dijkstra and API while making the DB the runtime data source. Changes require restart.

**Ruling:** Explicit extra_float_digits=3 is required because the hosted role otherwise rounded retrieved costs to 15 significant digits. Exact source/DB parity passed after correction.

**Evidence:** server tests16 passed, full DB smoke (including repeated import and rollback) passed, five-table RLS and SRID4326 geometry validity passed. Independent code review found no blocking issue. Android UI rerun is tracked separately in verification/database-integration-2026-10-26.md.

**Review focus:** Existing DATABASE_URL wins over local file; credentials never printed; all directed edges and graph-node membership preserved; immutable bundle completeness checked before use; scoring versions and stale-data restrictions retained; DB snapshot mode is reported accurately.
