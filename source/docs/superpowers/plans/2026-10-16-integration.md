## 인터페이스

Python 서버는 개발 시 localhost:8765, 기기는 adb reverse로 연결한다. 앱의 API_BASE_URL은 local.properties로 지정할 수 있으며 기본은 http://127.0.0.1:8765다. 개발용 HTTP는 debug 빌드의 loopback에만 허용한다. 키나 서버 좌표를 로그에 출력하지 않는다.

POST /v1/routes/compare는 명세의 named-coordinate origin/destination을 받고 RouteBundle envelope를 반환한다. 클라이언트는 geometry의 lon/lat, 유한수, 상태, 버전을 검사하고 실패한 조회를 성공으로 바꾸지 않는다. 최신 요청만 화면에 반영한다.

즐겨찾기는 명시적으로 저장한 OSM/사용자 지정 endpoint와 자체 RouteBundle 스냅샷만 Room에 보관한다. TMAP 검색 응답 장기 보관은 이번 흐름에 포함하지 않는다.

## 제약

실제 출구/교문 연결과 야간 보행 가능 여부는 코드만으로 검증할 수 없다. 현재 가로등 자료 미확보와 과거 시설 자료의 기준일을 숨기지 않으며 부분 실험 지표를 현재 검증된 안전점수로 표시하지 않는다. Supabase 접속정보는 보안 파일로 별도 제공받기 전까지 연결 성공으로 보고하지 않는다.

## 최종 검증 상태

Android 단위14개와 서버 단위11개 통과, lint 오류0/경고47, Debug APK 생성. PostGIS는 스키마·도구 준비만 완료했으며 실제 DB 연결은 미실행이다. UI 최종 결과는 verification/integration-ui.md와 log/log-2026-10-16-integration.md에 기록한다.
