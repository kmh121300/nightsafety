# 하단 경로 패널 세 단계 전환

작성일: 2026-11-20 · 최종 수정일: 2026-11-20 · 시간 기준: Asia/Seoul

사용자가 승인한 동작: 아래로 상세→요약→완전 숨김, 위로 숨김→요약→상세. 초기 상태는 기존 요약이다. 숨김에서도 아래 가장자리 위로 스와이프 또는 접근성 클릭으로 요약 복귀. 기존 전체화면/DB/점수와 별개다.

1. 기존 Smoke를 쓰는 에뮬레이터 회귀 검사 추가. 기존 APK에서 숨김 실패를 확인한다.
2. activity_main.xml의 Material BottomSheetBehavior 숨김 활성화 및 투명 복귀 영역/설명 추가. MainActivity에서 상세 상태의 숨김을 제한해 요약을 거치고, 숨김에 맞춰 지도 여백/버튼·복귀 영역을 갱신한다. 태블릿 고정 패널은 유지한다.
3. 빌드·단위·lintDebug 검사 후 새 APK 동일 해시 설치, API35 일반/작은 화면 단계 전환·전체화면 복귀·DB 검색 검사. 결과를 로그와 ROADMAP에 기록한다.

범위: MainActivity, activity_main, strings 및 지정 회귀 검사. 상단 UI 문제는 이번 범위에 포함하지 않는다. 새 의존성/DB 변경 없음.
