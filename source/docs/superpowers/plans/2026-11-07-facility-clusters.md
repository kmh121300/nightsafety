# Facility marker grouping implementation plan

작성일: 2026-11-07 · 최종 수정일: 2026-11-07 · 시간 기준: Asia/Seoul

사용자 승인 요구: 겹친 마커를 대표 아이콘 하나와 +N(총2개면+2)으로 표시하고 터치하면 포함 시설 목록, 항목 터치로 기존 상세. 동일 동작을 TMAP/로컬에 적용한다. 구현 선택: 실제 화면 픽셀 기준 단일28dp/묶음48×36dp 배지 충돌을 병합하고 확대/축소/회전/크기/필터/경로 변경 시 다시 계산한다. 대표는 안정적인 첫 시설 좌표이며 데이터 좌표를 변경하지 않는다. polygon은 기존 영역 표시. 기존100m 표시·시설 집계/점수·서버/DB/Room은 유지한다.

- [x] 순수 화면 묶음 로직의 겹침/분리/배지 재충돌/필터/대표 안정성 회귀를 먼저 실패 확인한다.
- [x] 공통 묶음/숫자 배지를 구현하고 native SDK 투영·카메라 이벤트/기존 overlay 배치와 로컬 그리기/터치에 연결한다.
- [x] 공통 시설 목록→상세 연결, 종료/재검색/필터 회귀를 확인한다.
- [x] 단위/lint/build·API35 두 지도 캡처/목록/상세/확대/필터를 확인하고 APK·해시·로드맵·로그를 갱신한다.

새 의존성/DB 변경/좌표 이동 없음. 화면 묶음은 표시 전용이며 시설 기록 수와 공식 점수는 묶음 수로 바꾸지 않는다. 카메라 이벤트는 잠깐 지연 후 처리해 매 프레임 SDK 객체를 전부 교체하지 않는다.
