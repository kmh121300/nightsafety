# TMAP Vector SDK

Official Android Vector SDK 3.7 bundle downloaded 2026-10-16:
https://tmapapi.tmapmobility.com/main.html#androidVSM/sample/androidSample.sdk_download

Bundled libraries: `tmap-sdk-3.7.aar` and `vsm-tmap-sdk-v2-eaa-2.0.14.aar`.
Official sample requires `com.google.flatbuffers:flatbuffers-java:24.3.25`.
SDK use and distribution remain subject to TMAP's terms; these binaries are not project-owned code.

The official 3.7 sample Gradle file still names tmap-sdk-3.6.aar. This app uses the actual 3.7 library shipped in the bundle.
