## 확인한 동작

지도 타일·경로·시설 마커 표시, 바텀시트 위/아래 드래그, 지도 전체화면 진입과 화면 복귀를 관찰했다. 지도 영역은 [0,0][1080,2220], 접힌 시트는 y1890~2220, 펼친 시트는 y352~2220으로 측정됐다. 마지막에는 시트를 접힌 상태로 돌렸다. 전체 기능/제스처 안정성 인수 검사는 아니다.

## 발견 사항 — 미수정

1. **상단 지도 버튼/저장 목록/상태바가 겹친다.** 기본 캡처에서 내 위치·전체화면 버튼 위에 저장 목록이 겹치고 상태 아이콘도 지도 버튼 영역과 겹친다. `layout-h720dp/view_map_panel.xml`에 기존 top/end 88dp 세로 버튼 레이아웃이 남아 있다. 기본 `layout/view_map_panel.xml`만 새 center_vertical/end 스타일로 변경돼 이 높이의 화면에서는 이전 variant가 선택된다. 전체화면 버튼 측정 위치는 [816,165][1058,297]이다.
2. **접힌 시트의 하단 요약이 잘린다.** 120dp peek 영역에 제목·경로 선택·요약이 모두 들어가지 않아 기본 화면 아래 요약 문구가 화면 끝에 걸린다. 탐색 막대 공간까지 포함해 실제 접힌 높이와 표시 항목을 조정할 필요가 있다.
3. **제목/부제/상태 글자가 지도 글자와 겹쳐 읽기 어렵다.** 툴바 배경이 투명해 지도 POI와 도로명이 그대로 비친다. 검색 카드처럼 배경을 제공하거나 지도와 겹치지 않는 배치가 필요하다.

## 환경/과거 캡처

시작 시 연결 기기가 없었다. 기존 시험 VM은 Google 부팅 화면 지연, 새 SwiftShader VM은 검은 화면/외부 System UI ANR로 정상 검토가 어려웠다. 원래 데이터를 삭제하지 않고 새 임시 VM의 GPU만 host로 바꾼 뒤 화면을 확보했다. 외부 시스템 창 Wait 처리1회가 측정 기록에 있으며, 이전 시도에서는 해당 시스템 창을 닫은 이력도 있다. 앱 ANR을 성공으로 처리한 기록은 아니다.

기존 naver_map_style.png/naver_map_collapsed.png/naver_map_bottomsheet_expanded.png는 UTF-16 BOM과 replacement 문자로 시작하며 PNG 서명이 무효라 이미지 도구에서 열리지 않았다. 원본은 보존했다. 새 캡처는 subprocess의 바이너리 바이트로 저장했고 이미지 도구에서 직접 열어 확인했다.
