# 상단 카드 최소화·확대 검증

작성일: 2026-11-20 · 최종 수정일: 2026-11-20 · 시간 기준: Asia/Seoul

## 구현 범위

사용자가 승인한 상단 카드 최소화 버튼과 오른쪽 위 사방 대각선 화살표 확대 버튼을 추가했다. 펼친 카드의 상태 문구 옆 `−` 버튼으로 상단 제목/검색 전체를 접고, 접힌 상태에서 오른쪽 위 확대 버튼으로 복귀한다. 아이콘24dp/터치48dp이며 접근성 설명을 제공한다.

MainActivity에서 최소화 여부를 별도 상태로 관리하고 savedInstanceState에 저장한다. 전체화면에서는 확대 버튼도 숨기며 복귀하면 최소화 여부를 유지한다. 하단 패널은 변경하지 않는다. 지도 가시 영역과 출처 문구 위치를 실제 상단 카드 높이/최소화 여부에 맞춰 갱신해 펼친 카드가 출처를 가리지 않게 했다. 태블릿 고정 레이아웃은 기존대로 사용하며 최소화 버튼을 노출하지 않는다. 새 의존성·DB·점수·자산 데이터 변경 없음.
