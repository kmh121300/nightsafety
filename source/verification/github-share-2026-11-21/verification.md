# GitHub 공유용 제외 규칙 보완 검증

작성일: 2026-11-21 · 최종 수정일: 2026-11-21 · 시간 기준: Asia/Seoul

## 변경

사용자 승인으로 root `.gitignore`를 추가하고 source/.gitignore를 보완했다. 로컬 설정/환경 파일과 변형·백업, 서명 키·개인 키, ZIP/APK 등 전달/배포 산출물, 빌드/가상환경/캐시, 로컬 DB를 제외한다. `.env.example`과 `local.properties.example`은 예외로 포함한다. 기존 파일은 삭제하지 않았고 실제 키·DB 설정도 수정하지 않았다.

값이 빈 Android/선택적 DB 예시를 추가했다. root/source README에 전체 폴더 구조 유지, 로컬 설정 준비, 키가 없을 때 로컬 지도/동봉 데이터 실행, 기존 설정 덮어쓰기 방지, 웹 직접 업로드/강제 추가·과거 커밋의 별도 확인을 안내했다. SDK AAR·Gradle wrapper·앱 자산·CSV/OSM 입력은 포함 대상에 유지한다.

## 2026-11-21 검사

환경: Windows/PowerShell/Python/Git, 대상은 이 변경 직후의 작업 폴더다. 프로젝트 root/source에 기존 Git 저장소가 없으므로 프로젝트 밖 임시 bare 저장소와 `--work-tree`를 사용했다. 전역 제외 규칙을 비우고 실제 프로젝트 규칙만 검사했다. 프로젝트에는 git init/커밋/푸시를 하지 않았다.

- 과거 실제 키가 발견된 root ZIP1개/APK10개, 현재 local.properties/.env.local/빌드 APK가 제외됨을 확인했다.
- 변형 환경 파일·중첩 설정·개인 키/서명 키·백업 압축·생성물 경로도 `git check-ignore --no-index`로 검사했다. 일부는 현재 파일이 없는 회귀용 경로이며 실제 비밀 파일을 새로 만든 것이 아니다.
- 설정 예시2개, Gradle 실행 파일/래퍼 JAR/설정, SDK AAR2개, 서버 실행 파일/requirements, 앱 자산4개, raw.osm/poc.py가 실제 후보에 포함됨을 확인했다.
- 최초 정제 후 검사 시점701개/132,240,110바이트. 이후 추가된 검사 문서/결과 파일은 이 수치에 포함하지 않는다.
- 후보 파일의 현재 로컬 TMAP 키·DB 연결/비밀번호 일치 검사와 개인키 헤더/GitHub 토큰/AWS 키/비밀번호 포함 DB URI 패턴 검사에서 일치0건. 포함 대상 JAR/AAR 내부의 중첩 ZIP도 알려진 값으로 대조했다(7개 archive, 크기 제한으로 건너뛴 멤버0개). 값은 결과에 기록하지 않았다.
- 임시 저장소에서 실제 `git add --all` 후 인덱스 경로가 예상 후보와 정확히 일치함을 확인했다. 문제 산출물과 개인 설정은 인덱스에 없고 필수 파일은 있다.
- [규칙/필수 파일/비밀값 검사 및 임시 Git 추가 결과](verification.json).
- 문서/링크 보완 후 [최종 재검사](final.json)도 PASS. Git2.54.0.windows.1, 검사 시점704개/132,252,895바이트. UTF-16 BOM 출력17개도 정규화해 대조하고 중첩 archive7개를 다시 검사했다. 알려진 값/일반 비밀 패턴0건, 임시 git add와 후보 일치, 설정 예시의 빈 값/필수 URL·문서 날짜/링크·규칙 해시 일치 확인. 실제 키 포함 과거 산출물은 로컬에 남고 Git에서만 제외됨도 확인했다. 최종 결과 파일 자체는 이 후보 수치 생성 뒤 추가됐다.

## 범위와 한계

이 검사는 현재 소스 트리의 공유 준비 검사이며 모든 보안 취약점/미지의 비밀값 탐지를 보증하지 않는다. 이미지 OCR·난독화/암호화된 비밀값·과거 원격 GitHub 이력·SDK/데이터 재배포 조건은 미검증이다. `.gitignore`는 웹 직접 업로드·강제 추가·이미 추적된 파일을 제거하지 않는다.

앱/서버 실행 코드는 변경하지 않았으므로 앱 빌드/DB/API 재검사를 실행하지 않았다. 기존 앱 기능·실기기/현장 인수 상태는 유지한다. 실제 GitHub 업로드는 하지 않았다.
