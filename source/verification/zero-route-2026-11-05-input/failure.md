# API36.1 이미지에서 입력 단계 중단

작성일: 2026-11-05 · 최종 수정일: 2026-11-05 · 시간 기준: Asia/Seoul

시스템 창 처리 보완 뒤 정상 경로의 세 숫자 점수 확인은 통과했다. 이어지는 보행 지점 입력에서 place_query를100초 동안 찾지 못해 검사가 중단됐다. [당시 캡처](input-failure.png)와 후속 조회에서 앱 PID가 없고 NexusLauncher가 앞에 있었다. 앱 대상 Java crash 기록과 종료 이력은 확인되지 않아 정확한 종료 원인은 미확정이다. 이 실행은0거리 UI 통과가 아니다.

실패를 보존하고, 이번에 기동한 API36.1 이미지의 emulator-5558만 종료했다. 기존에 UI 검증을 통과한 API35 Pixel_3a 임시 데이터 환경/emulator-5556에서 동일 APK로 재검사를 진행한다. 앱·서버·DB를 수정해 통과로 바꾼 것은 아니다.
