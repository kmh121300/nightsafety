## 원천과 이용조건 근거

- [행정안전부 CCTV 파일](https://www.data.go.kr/data/15075538/fileData.do): 무료·이용허락범위 제한 없음, 원본 링크와 메타데이터 갱신 안내 확인.
- [CCTV 조회서비스](https://www.data.go.kr/data/15155042/openapi.do): 개발/운영 자동승인 안내와 인증키/활용신청 확인 경로. 실제 키 발급/호출은 하지 않음.
- [전국안전비상벨위치 표준](https://www.data.go.kr/data/15028206/standard.do): 무료·이용허락범위 제한 없음. 원본은 [비상벨 조회사이트](https://file.localdata.go.kr/file/emergency_call_box_info/info). 메타데이터는 EPSG5174를 안내하므로 실제 파일의 좌표 종류/값을 확인하기 전 기존 위경도 변환을 그대로 적용하거나 무조건 재투영하지 않음.
- [CCTV 원본 조회사이트](https://file.localdata.go.kr/file/cctv_info/info): 이번 CLI/웹 도구에서 본문 조회 실패. CLI는403이며 이것이 사용자 브라우저의 접근 실패나 로그인 필수임을 증명하지 않음.
- [경기데이터드림 CCTV](https://data.gg.go.kr/portal/data/service/selectServicePage.do?infId=VIPK0N53968Q7DV5TT2312643570&infSeq=3), [안전비상벨 API 안내](https://data.gg.go.kr/portal/data/service/selectServicePage.do?infId=64I5OUQUMRCWUEZI5WAQ27006963&infSeq=3): 공개 API 안내에서 sample key는 pIndex1/pSize5 고정임을 확인. 요청 크기나 페이지 변경으로 샘플 제한을 우회하지 않음.
- [보안등 정보 후보](https://www.data.go.kr/data/75232/linkedData.do), [경기도 제공처](https://data.gg.go.kr/portal/data/service/selectServicePage.do?infId=VEY71398U2941WM4E7PV21507518&infSeq=1): 공개 제목·설명은 확인했으나 상세 표와 이용허락범위는 이번 응답에서 확인되지 않음.
- [전국보안등 표준](https://www.data.go.kr/data/15017320/standard.do): 위도/경도와 기준일 컬럼, 5만건 다운로드 상한 및 전체 API 안내를 확인. 표시된 일부 지역을 시흥으로 간주하지 않음.
- [가로등 집계](https://www.data.go.kr/data/15058853/openapi.do): 개별 좌표가 아닌 시군별 집계임을 확인.

위 이용조건 확인은 해당 공식 원천의 안내이며, 기존 사용자가 제공한 CSV가 이 원천과 동일한 다운로드라는 것을 증명하지 않는다. 원본 파일과 내려받은 경로·시점을 함께 확보한 뒤 출처를 연결해야 한다.

## 실제 공개 API/사이트 응답

직접 호출 시각은 2026-10-27 13:15 KST 전후이며 키·로그인 없이 조회했다. [checks.json](data-source-2026-10-27/checks.json)에 URL/UTC 확인시각/HTTP 상태/응답 해시를 기록했고 원문 응답을 같은 폴더에 저장했다.

1. `Smartstlamp?Type=json&pIndex=1&pSize=100`: HTTP200, Content-Type은text/html이나 본문은 유효 JSON. head의 총71건과 실제5건을 구분했다. 샘플 주소는 만안구이며 기준일20260206.
2. `Smartstlamp`에 `SIGUN_NM=시흥시` 추가: HTTP200, RESULT/INFO-200(해당하는 데이터가 없습니다). 필터 컬럼의 유효성·전수 반환이 확인되지 않았으므로 시흥 전체0건으로 결론내리지 않는다.
3. 경기데이터드림 CCTV/보안등 페이지: HTTP200/제목 확인. 정적 응답은 기본정보 영역까지이고 실제 데이터/라이선스 상세가 반환되지 않았다.
4. `file.localdata.go.kr/file/cctv_info/info`: HTTP403. 우회·로그인·반복 대량 호출을 하지 않았다.
5. 공공데이터포털 검색: HTTP200, 비상벨 표준의 공식 ID15028206과 원천 링크 확인.
6. 비상벨 원본 URL은 웹 조회 도구에서도 열리지 않았다. 해당 URL의 HTTP 상태코드는 확인하지 못했으므로 CCTV에서 확인한403을 비상벨의 확인된 상태코드로 복사하지 않는다.

기본 sandbox의 네트워크 차단은 [checks-sandbox.json](data-source-2026-10-27/checks-sandbox.json)에 따로 보존했다. 이후 승인된 네트워크 환경의 결과만 원천 서비스 상태로 판정했다. 브라우저 제어 도구에는 사용 가능한 브라우저가 없어 동적 표의 UI 검사는 수행하지 못했다.

## 사용자 도움이 필요한 부분

현재 필요한 도움은 가로등/조명 자료에 한정한다. CCTV/비상벨은 사용자가 확인한 기존 최신 CSV를 이용한다.

1. 시흥 가로등/보안등/스마트가로등의 위치 원본 파일이 있다면 출처·기준일·이용조건과 함께 확보한다. 종류를 구분해 확인한다. CCTV/비상벨 파일 재요청은 하지 않는다.
2. 경기데이터드림 Open API 인증키 발급/준비. 공개 샘플5건을 넘어서 조명 자료의 실제 수록 범위를 확인하는 데 사용한다. **키 발급만으로 최신 시흥 가로등의 존재나 전수 확보가 보장되지는 않는다.** TMAP 앱키나 DB 비밀번호를 대신 사용하지 않는다.

키/로그인 정보는 채팅·문서·로그에 붙이지 않고 로컬 비밀 설정으로 전달한다. 실제 시흥 조명 자료가 원천에 없다면 사용자가 시흥시 관리기관에 좌표·시설종류·관리번호·기준일·이용조건의 제공을 신청해야 할 수 있다. 이번에는 메시지/제공신청을 보내지 않았다.

## 결론과 미검증 범위

R5의 공개 자료원 확인은 수행했고, 실제 최신 시흥 데이터 확보·검사는 다음 단계다. 가로등/보안등/스마트가로등을 임의로 같은 유형으로 바꾸지 않는다. 수집 자료의 현재 작동·야간 접근성·실제 조도는 위치 좌표만으로 검증되지 않는다. 이번 작업은 앱 빌드/DB 연결/기존 데이터 import를 다시 실행하지 않았다.
