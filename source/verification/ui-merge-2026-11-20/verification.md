- Windows, Pixel_3a AVD / emulator-5556 / Android15(API35), host GPU.
- 기본1080×2220 / 440dpi, 임시 작은 화면720×1280 / 360dpi(320×568dp).
- 대상 APK: source/app/build/outputs/apk/debug/app-debug.apk
- SHA-256: e3aa9b935e3e95419c69b38ba1f5ea7499de9464cfc9f4cfd3e81bab55d0ff2f. 설치 APK 해시 일치 확인.
- DB snapshot 서버 시작은 실패했다([초기 결과](server-stderr.txt)). 설정 파일 변경 없이 검사 프로세스에서 DATABASE_URL을 비워 로컬 원본 Engine으로 서버를 시작했다. 첫 대체 실행은 import 경로 누락으로 실패했고, 경로 보완 후 서버 준비/검색 성공. DB 성공으로 해석하지 않는다.

## 발견 사항: 수정 필요

1. 최초 어두운 지도 배경에서 상태바 시간/아이콘 대비가 낮다. MainActivity.kt의 `SYSTEM_UI_FLAG_LIGHT_STATUS_BAR` 설정(92행)이 밝은 배경용 아이콘을 강제한다. 앞선 styles 변경만으로는 해결되지 않았다. 로컬 미리보기의 상단 안내 문구도 시스템 상태바 영역과 겹친다.
2. 작은 화면에서 툴바 부제 `대학–정왕역 · 보행 경로 비교`가 단어 중간에서 두 줄로 나뉜다. 상단 카드 높이가 커지고 지도 출처 문구가 일부 가려진다(10-small.png). 일반 화면 출처도 카드 바로 아래에 붙어 있어 위치 조정 검토가 필요하다.

이번 요청은 에뮬레이터 확인이므로 앱 코드는 추가 수정하지 않았다. 결과는 일부 동작 통과·화면 문제 발견이며 UI 전체 인수 완료가 아니다. 실기기/GPS/OEM·태블릿·가로·전체 명세·DB 복원은 미검증이다. 에뮬레이터와 로컬 개발 서버는 확인 가능한 상태로 유지했다.
## 2026-11-20 DB 재활성화 후 재검사

사용자 DB 재활성화 후 서버를8766포트에서 직접 실행했다. 백그라운드 실행 명령은 자동 승인 검토에서 거부되어 직접 실행으로 진행했다. 기존8765 로컬 서버는 유지하고 에뮬레이터 reverse를 기기8765→호스트8766으로 전환했다.

- Windows/API35 emulator-5556, APK는 동일 SHA-256 병합본.
- [DB health](db-health.json): configured=true, verified=true, mode=startup_snapshot. 시작 시 PostGIS 스냅샷을 읽고 경로 계산은 메모리 Dijkstra에서 수행한다.
- DB 원천 시설: CCTV270·비상벨238·보안등870, 총1378개. 앱 표시용 기타 시설을 포함하는1381과 구분한다.
- [DB 경로 검색](12-db-search.png) 및 [지표 화면](13-db-metrics.png) 확인. 전체9.1·평균13.0·취약0.0, 주변 CCTV16·비상벨16·보안등12 표시.
- 기본 도착지는 연결 미완결·간격12.56m 안내 유지. 완결 경로/현장 보행 성공을 의미하지 않는다.
- [UI XML](db-ui.xml). 지정 검색 중 crash/ANR 대화상자 관찰 없음. DB 쓰기/재가져오기/전체 인수·실기기 재검사는 하지 않았다.
- DB 서버와 에뮬레이터 연결을 유지했다. 앞선 실패 기록은 당시 결과로 보존한다.
