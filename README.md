## 팀 공유와 첫 실행

저장소는 이 README가 있는 최상위 폴더부터 공유합니다. 서버가 `night-safety-project-readiness/osm_poc_v2`를 사용하므로 `source`만 따로 내려받으면 서버 자료/모듈이 빠집니다. Android Studio에서는 `source`를 엽니다. 자세한 실행 순서는 [실행 안내](source/README.md)를 따릅니다.

- 키가 없는 [Android 설정 예시](source/local.properties.example)와 [선택적 DB 설정 예시](source/.env.example)를 각자의 로컬 설정으로 복사합니다. 기존 설정을 덮어쓰지 않습니다.
- 실제 local.properties/.env 설정, 서명 키, ZIP/APK 등 전달·배포 산출물과 빌드/가상환경은 Git 제외 대상입니다. 과거 전달 ZIP/APK를 GitHub 웹 화면에 직접 올리지 않습니다. `.gitignore`는 Git을 통한 추가에 적용되며 수동 파일 업로드나 강제 추가를 막지는 않습니다.
- Gradle wrapper·SDK AAR·앱 자산·CSV/OSM 원본은 실행을 위한 소스 후보에 유지합니다. [SDK 이용/배포 조건 안내](source/app/libs/README.md)를 확인하고, 공개 저장소 전환 전 SDK/데이터 재배포 허용 여부는 별도 확인합니다.
- 기존 원격 저장소에 연결한다면 이미 추적/업로드된 비밀 파일이 없는지 그 이력도 확인해야 합니다. 제외 규칙은 과거 커밋의 값을 지우지 않습니다.
