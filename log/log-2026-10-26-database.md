# 밤길 지킴이 DB 통합 — 2026-10-26

작성일: 2026-10-26 · 최종 수정일: 2026-10-26 · 작업/검증 기준일: 2026-10-26 · 시간 기준: Asia/Seoul

현재 전체 상태는 [로드맵](../ROADMAP.md), 이번 문서 관리 변경은 [문서 개선 로그](log-2026-10-26-documentation.md)를 확인합니다. 아래 DB/API 결과와 앱 UI 미완료 상태를 구분합니다.

사용자 승인 범위: 준비한 실제 DB에 테이블/데이터 생성, 저장 검증, 서버 연결과 앱 연동 확인.

기존 safenight 스키마와 extensions의 PostGIS를 사용하도록 가져오기 도구와 스키마를 수정했다. 버전별 노드·시설·간선·계산 구간을 원자적으로 저장하고 서버 시작 시 읽기 전용으로 복원한다. Android API와 기존 Dijkstra 및 과거자료 제한은 유지한다. DATABASE_URL 없이 기존 로컬 파일 모드도 유지한다.

실제 저장: OSM 노드27,607 / CCTV·비상벨508 / 방향별 간선8,208 / 계산 구간22,256. 재가져오기 중복 없음과 잘못된 geometry 가져오기의 rollback을 확인했다. 원본 전체 데이터와 DB 복원 데이터 및 경로 API가 일치한다. 서버 테스트16개 통과, 별도 코드 검토에서 차단 문제 없음.

DB 숫자 출력 정밀도 때문에 최초 원본 비교가 실패했다. extra_float_digits=3 설정으로 보정한 뒤 전체 대조 검사 통과. 에뮬레이터 System UI 응답 없음으로 최초 UI 검사는 실패했으며 DB/API 성공과 구분해 기록한다.

화면 깨우기·시스템 창 정리 후 재시도2회도 지도 준비 UI에서 시간 초과했다. 앱 전체 UI 검사는 미완료이며 Android 소스 변경·새 APK 빌드는 하지 않았다. DB에서 읽은 자료를 이용하는 HTTP 계약과 원본 데이터 대조는 마지막 재검사도 통과했다.

실행 환경: source/.venv와 source/.env.local을 Git 제외. 연결정보 출력 없음. 로컬 서버127.0.0.1:8765 실행. 실제 사용법과 검증 한계는 [검증 기록](../source/verification/database-integration-2026-10-26.md) 및 [서버 안내](../source/server/README.md)에 있다.
