# MVP UI 정리

작성일: 2026-11-05 · 최종 수정일: 2026-11-05 · 시간 기준: Asia/Seoul

사용자가1번 UI 정리를 위임하고 최종 UI 검사는 나중에 직접 하겠다고 했다. 중간 디자인 승인 없이 기존 Kotlin/XML·Activity·동작 ID를 재사용해 적용한다. [작업 계획](../source/docs/superpowers/plans/2026-11-05-ui-polish.md).

## 변경 범위

- 네이비/청록·밝은 바탕·흰색 영역과48dp 컨트롤. 검색·지도·경로 비교/시설 구분, 세로/가로/600dp 이상 두 열 배치.
- 전체/평균/취약 지표 숫자 카드, 거리·시간·점수를 포함한 경로 선택, 결과 없는 경우 이전 숫자 초기화. 필터·Room 저장/재조회·0거리/부분·미완결·원천 표시는 보존.
- 출처/실제 데이터 기준일은 자료 정보에, OSM 표기는 지도에 표시. 시설 상세는 주소·기관·목적·경찰연계·좌표·기준일·출처·좌표 공유 기록을 읽기 쉬운 형태로 제공. 원본 누락은 정보 없음/미기록으로 표시하며 주소를 생성하지 않음.
- backend·DB·자료/점수 정책·원본 asset/CSV는 변경하지 않는다. 새 의존성과 화면 탐색 구조를 추가하지 않는다.

## 검증 진행

시설 상세의 내부 키 대신 사용자용 정보 표시 회귀는 기존 구현에서2개 assertion 실패를 확인한 뒤 수정했다. 읽기 전용 코드 검토에서 OSM 경찰시설의 후보 자격 누락을 발견했고, 회귀1개 실패를 확인한 뒤 목록·필터·상세에 후보 표시를 보완했다. 이는 제외하기로 한 시설 작동 여부 안내와 다른 정보다.

2026-11-05 Windows/Android SDK35 임시 Pixel_3a 환경. 최종 Android22개·도구5개 통과, APK 빌드와 lint 오류0/경고24 통과. 초기 lint의 API27 속성 오류는 values-v27 분리 후 해소했다. 확대 글꼴에서 점수 카드 높이가 늘어나도록 적용했다. 최종 APK SHA256: `aa54064af7c5654442af8df830286283dae72c79296e3113e0eae194003d78d0`.

최초 임시 Android 부팅/시스템 서비스 준비 실패로 설치와 UI 검사가 시작되지 못했다. 이후 기존 검증용 임시 이미지와 관리 가능한 실행 세션으로 설치에 성공했다. 중간 에뮬레이터 중복 실행은 AVD 잠금 오류로 거절됐으며 기존 AVD/사용자 자료를 초기화하지 않았다. 새 APK의 지도/시설1,381개·기본 검색 후보3개와 정식 지표/미완결 표시까지 통과했고 전체 UI 검증을 진행 중이다.

서버는 기존 DB의 `local-mvp-3types-v1` snapshot을 정상 로드했다. 서버/DB 코드 변경이 없어 새 import/전체 DB 검사를 반복하지 않는다. 이후 세로 전체 UI와 가로/태블릿 크기·상세/자료/0거리 화면을 확인하고 캡처를 남긴다.

사용자의 최종 디자인/사용성 검사는 대기 상태로 유지한다. 개발 검증이 통과해도 사용자 인수 완료로 바꾸지 않는다. 실기기 GPS·현장·배포·명세 전체 미검증은 별도다.

관련: [로드맵](../ROADMAP.md), [현재 점수 정책](../md/night-safety-mvp-scoring-policy-ko.md).

Android 시스템 ANR 창2회도 관찰해 기록했고 연결/부팅 완료 후 재시도했다. 12:49 두 번째 검사는 필터 조작 단계의 `route_summary` 미발견으로 중단됐으며 캡처에는 즐겨찾기 저장 창이 열려 있었다. 안정 상태의 실제 필터 토글/결과 스크롤은 정상 확인했다. 스크롤 직후 좌표를 재조회하지 않는 검사 도구의 클릭 경로를 회귀 실패로 확인하고, 안정 대기와 클릭 직전 bounds 재조회로 보완했다. 도구 검사는 총6개 통과이며 APK는 변경하지 않았다. 전체 UI를 다시 검사한다.

실패 기록: [12:42 ADB](../source/verification/android-2026-11-05_123635_815055/failure.md), [12:49 좌표 조작](../source/verification/android-2026-11-05_124311_435170/failure.md). 사용자 인수 완료로 표시하지 않는다.

bounded batch·빠른 필터 반전·지도 종료 회귀3개를 먼저 추가했고 미구현으로 실패한 뒤 구현했다. 전체 Android/빌드/lint·새 APK·실행 UI는 재검증 중이다. 코드 검토도 추가 요청했다. 검사 도구에는 클릭 전 좌표 재조회와 버튼 밖 가장자리 스크롤 회귀2개를 추가해 총7개 통과했다.

## 13:37 KST 재부팅 전 중단

ANR 수정 APK SHA256 `1b4d9a5e19eaa43174bbb8ebc864b44f60c671952ff81d8a9713946ee6a3e6ad`, Android25개·도구7개·lint 오류0/경고24·빌드·13:21 [기본 UI8개](../source/verification/android-2026-11-05_130904_166965/integration-ui.md) 통과. 설치 해시 일치와 자료/시설 상세도 확인했고 추가 코드 검토에서 중요한 결함은 없었다.

추가 화면 검사에서 회전 점수 유실과 확대 글꼴 헤더 잘림을 발견했다. 같은 PID13979·도착지 이름 보존 상태로 점수9.1→—를 재현했다. 헤더 XML만 가변 높이/폭으로 수정했고 이 변경은 미빌드다. 보완된0거리 검사도 미실행이다. 전체 UI 완료로 처리하지 않는다.

사용자 재부팅 요청으로 추가 수정/검사를 중단했다. 정확한 코드/APK 차이·환경·다음 시작점은 **[재시작 인계](log-2026-11-05-ui-reboot-handoff.md)**에 기록했다. 회전 상태 보존부터 이어간다. 임시 에뮬레이터와 로컬 서버를 종료했으며 이미지·APK·소스·실패 캡처는 보존했다.
