# R4 Android 빌드와 앱 검사

작성일: 2026-10-26 · 최종 수정일: 2026-10-26 · 시간 기준: Asia/Seoul

사용자 승인으로 전체 로드맵 R4를 시작했다. 현재 소스의 Android 테스트14개와 새 APK 생성(캐시 무시 재실행) 통과, lint 오류0/경고49개를 확인했다. 서버 health는 safenight DB snapshot 모드로 ready였다.

UI 도구가 과거 증거를 덮어쓰는 문제는 회귀 검사2개로 재현한 뒤 날짜/시각별 출력으로 수정했다. 회귀2개 통과. 앱 동작 코드에는 아직 수정하지 않았다.

WHPX 사용 가능을 확인하고 기존 Pixel_3a/API35를 호스트 GPU로 부팅했다. 새 APK 설치 후 화면 유지/잠금 상태를 통제해 지도 준비 및 전체 흐름을 검사 중이다. 원래 화면 설정은 시험 후 복구한다. 실제 연결 휴대폰은 없었으며 사용자에게 연결 가능 여부를 물었다.

상세 결과와 실제 검증 날짜: [R4 검증](../source/verification/android-r4-2026-10-26.md). 다음 진행 상태는 [전체 로드맵](../ROADMAP.md)에 반영한다.
