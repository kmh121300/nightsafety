# R6 MVP 점수·표시 정책 논의

작성일: 2026-11-03 · 최종 수정일: 2026-11-03 · 시간 기준: Asia/Seoul

## 사용자 결정

UI 개선·실기기 검사에 앞서 R6 점수 정책을 논의한다. 사용자는 자료 허용기간 삭제를 제안했고, MVP에서 '현재 시설 작동 여부 미확인' 문구를 제외하도록 지시했다. 해당 문구는 MVP 정책안에서 제외하고 출처·데이터 기준일을 표시한다.

이는 사용자에게 보여주는 문구의 결정이며 내부 작동 상태를 정상/검증 완료로 바꾸는 결정은 아니다. 기존 현장 검증 기록과 미완료 상태는 보존한다. 자료 허용기간 삭제·보안등의 조명 점수 채택·점수 활성화의 상세 정책은 후속 설계에 반영할 논의 대상이며, 이번 기록으로 서버/API 점수를 활성화하지 않는다.

## 적용 상태와 확인

2026-11-03 Windows 작업 폴더에서 로드맵과 직전 정책 논의를 대조했다. 이번 변경은 정책 논의 기록과 로드맵 상태 갱신뿐이다. 기존 앱의 관련 문구 제거, 명세의 계산/인수 기준 수정, 서버·DB·APK 변경과 실행 검사는 수행하지 않았다. 문서 날짜·내부 링크·구현 전 상태를 확인한다. 코드 변경이 없어 앱 빌드와 DB 검사는 반복하지 않는다.
