# R5 공개 시설 자료원 조사

작성일: 2026-10-27 · 최종 수정일: 2026-10-27 · 시간 기준: Asia/Seoul

사용자 요청으로 가로등·최신 CCTV·비상벨의 공식 제공 경로, 시흥 수록, 기준일, 이용조건과 사용자 도움 필요성을 조사했다. [검증 기록](../source/verification/data-source-review-2026-10-27.md)과 [공개 직접 조회 증거](../source/verification/data-source-2026-10-27/checks.json)에 근거를 남겼다.

## 2026-10-27 결과

- CCTV·비상벨은 공식 원천·무료/이용허락범위 제한 없음 안내를 확인. 실제 최신 시흥 행과 기준일은 미확인. 원본 CCTV 조회사이트는 이 환경에서403.
- 스마트가로등 HTTP200/JSON 확인: 총수 표시71과 반환5를 구분. 샘플은 만안구/20260206이고 시흥 조건 INFO-200. 샘플 제한·필터 한계 때문에 시흥0건으로 결론내리지 않음.
- 보안등 위치 후보는 있지만 시흥 수록·이용조건·최신성 미확인. 가로등 집계는 좌표가 아니며 점수 입력으로 대체하지 않음.
- 공개 API 안내의 sample pIndex1/pSize5 고정을 확인. 제한 우회를 하지 않음. 브라우저 제어 도구에는 브라우저가 없어 동적 표 확인은 미수행.
- 사용자가 공식 CSV/Excel을 내려받거나 정식 API 키를 준비하면 다음 확인이 가능. 키만으로 시흥 조명 자료의 존재/최신성이 보장되지는 않음. 계정 생성·키 발급·기관 문의/신청은 하지 않음.

이번에는 코드·DB·앱 시설 자료·안전점수 정책을 변경하지 않았다. 앱 빌드/DB 재검사는 불필요하므로 실행하지 않았다. 사용자 제공 정보상 GPS 가능한 Android 태블릿이 집에 있으나 현재 연결/모델/GPS 수신은 확인되지 않았다. R4는 휴대폰만이 아니라 해당 태블릿으로도 이어갈 수 있는 실기기 대기로 기록한다.

최종 확인: 직접 조회 기록6개와 저장 응답 해시 일치, 샘플 반환5/총수표시71·만안구/20260206·시흥조건INFO-200 및 CCTV403을 저장 원문에서 재확인했다. 비상벨 원본 웹 조회도 실패했으나 HTTP코드는 미확인이므로403이라고 단정하지 않는다. 문서28개·내부 링크158개·기능38개·단계8개 검사 오류0을 확인했다.

## 2026-10-27 기존 CSV 보유 상태 재확인

사용자가 기존 csv 폴더를 지적해 파일을 직접 다시 읽었다. CCTV2130행/기준일2026-01-20, 비상벨1851행/기준일2026-01-22, 두 파일CP949를 확인했다. 이 파일은 이미 현재 앱/DB의 입력이며 같은 파일의 재전송 요청은 불필요하다. 앞선 요청은 기존 파일과 최신 갱신본을 명확히 구분하지 못했으므로 원천 조사 기록의 사용자 도움 항목을 정정했다. 추가 조사는 더 최근 갱신본 존재 여부와 가로등 자료 확보에 집중한다. 파일/DB/앱 데이터 변경이나 빌드 재실행은 하지 않았다.

## 2026-10-27 사용자 최신 자료 확인 반영

사용자가 두 CSV가 최신 정보라고 확인했다. 이를 현재 기준 자료로 유지하며 더 최신 파일 확인/재요청을 현재 작업에서 제외했다. 사용자 확인과 독립적인 원천 전수조회는 구분하고, 파일의 기준일2026-01-20/22와 실제 작동/현장 검증 상태 및 기존 점수 정책은 바꾸지 않았다. 다음 자료 작업은 미확보 시흥 가로등/조명 좌표 확보다. 로드맵·실행 안내·조사 기록을 같은 날짜로 갱신했다. 데이터/코드 변경·외부 재조회·앱 빌드/DB 재검사는 하지 않았다.
