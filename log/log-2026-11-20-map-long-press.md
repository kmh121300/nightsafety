# 지도 길게 누르기 경로 검색

작성일: 2026-11-20 · 최종 수정일: 2026-11-20 · 시간 기준: Asia/Seoul

## 후속 요청: 보정 확인 없이 자동 검색

사용자가 보행 지점 확인 창을 생략하고 출발지/도착지 메뉴 선택 직후 자동 보정·검색하도록 요청했다. 공통 snap 성공 처리에서 확인 창을 제거하고 기존 입력 반영/search를 바로 호출하도록 변경했다. 보정 거리 이름 표시·지역/오류 처리·요청 취소/최신 revision 검사는 유지한다. 새 APK 빌드/Android41개/lint 오류0·경고50 및 API35 TMAP 출발지/로컬 도착지 자동 검색 회귀 통과. DB snapshot verified=true 확인. 기존 확인 창 검증은 아래 과거 기록으로 보존한다. [최신 APK/실패·성공/캡처](../source/verification/map-auto-snap-2026-11-20/verification.md).

사용자 승인으로 TMAP/로컬 지도 길게 누르기 메뉴/가까운 보행 지점 보정 및 확인 후 검색을 구현했다. [계획](../source/docs/superpowers/plans/2026-11-20-map-long-press.md). 기존30m compare 제한과 파일럿 범위는 유지하고 별도 POST /v1/places/snap API를 추가했다. 가장 가까운 활성 graph node로 명시적으로 재선택해 검색하고, 원래 선택 좌표·보정 좌표·거리와 미검증 연결 안내를 표시한다. 경로 수치와 핀은 보정된 지점 기준이다. 실제 보행 연결을 승인하거나 DB/그래프/점수 정책을 수정하지 않는다. edge 임시 분할/파일럿 밖은 미지원이다.
