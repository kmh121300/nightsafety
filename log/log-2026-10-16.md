에뮬레이터의 런처/System UI/Digital Wellbeing 응답 없음이 실행 검사를 방해했다. 저장된 snapshot 없이 부팅하고 시스템 앱 오류 창을 처리한 뒤 검사를 완료했다. 앱 자체의 응답 없음은 테스트에서 실패로 처리한다. 테스트에서 변경한 Activity 재생성 설정은 복원했고, 작업용 headless 에뮬레이터는 검사 후 종료했다.

## 유지한 한계

- 경로는 Python PoC의 **고정된 실험 결과**다. 앱에서 사용자가 고른 임의 출발·도착 경로를 새로 계산하지 않는다.
- 정왕역 실제 출구까지 12.56m 연결이 미검증이며 `route_incomplete` 상태를 유지한다. 연결선을 임의 생성하지 않았다.
- 가로등 자료는 미확보이고 안전점수는 미산출이다. 보행선 우선 경로를 검증된 안전경로로 부르지 않는다.
- 시간은 거리 ÷ 1.2m/s 가정이며 실측 ETA가 아니다.
- 시설 좌표만으로 현재 작동·보행자 접근성·경찰시설 운영을 확인하지 않았다.
- 서버/API, PostgreSQL/PostGIS, 새 출발·도착 검색, Room 즐겨찾기는 아직 미구현이다.

## 앞으로 할 작업 — 권장 순서

### 1. 실제 TMAP 지도 통합 확인

- 팀 앱키를 `source/local.properties`의 `TMAP_APP_KEY`에 설정하고 다시 빌드한다. 키를 로그·채팅·저장소에 기록하지 않는다.
- 등록할 앱 패키지명은 `kr.ac.tukorea.nightsafety`다. 공급자가 요구하는 앱 등록·제한 조건을 확인한다.
- 실제 지도 위에서 시설 좌표·건물 polygon·경로 두 개·로고가 올바른 위치에 표시되는지 확인한다.
- 정상 인증, 인증 실패, 네트워크 실패와 로컬 보기 전환을 검사한다.
- **완료 기준:** 팀 키를 사용한 지도·마커·선의 실제 기기 또는 에뮬레이터 실행 증거.

### 2. 서버와 PostGIS의 최소 경로 조회 연결

- 기존 명세의 DTO·상태·버전 계약 중 첫 경로 조회에 필요한 범위를 구현한다.
- 기존 Python 탐색 코드를 요청 처리 함수와 파일 저장용 실행 코드로 분리한다. API 요청이 기존 조사 결과 파일을 덮어쓰지 않게 한다.
- 팀 DB에서 준비 SQL로 PostGIS/pgRouting 제공 여부를 확인하고 시설·파일럿 그래프를 import한다. 경로 탐색은 Python Dijkstra로 시작할 수 있다.
- 서비스 범위, 입력 좌표, 요청 크기, timeout과 비밀키 관리를 적용한다.
- **완료 기준:** 앱이 서버 결과를 받아 표시하고, 같은 출발·도착에서 기존 Python 결과와 비용·거리·미완결 상태가 일치.

### 3. 출발·도착 입력과 경로 검색 화면 연결

- 출발·도착 지정, 교환, 검색 요청, 범위 밖·경로 없음·미완결·네트워크 오류 상태를 연결한다.
- 입력 변경 시 이전 요청을 취소하고 최신 요청 결과만 반영한다.
- 실제 기기에서 위치 권한 허용·대략 위치·위치 꺼짐·시간 초과도 확인한다.
- **완료 기준:** 고정된 두 실험 경로 조회를 넘어 사용자가 선택한 입력으로 서버를 조회하는 흐름.

### 4. 시설 기반 지표와 자체 안전경로 구현

- 명세의 segment·표본·거리 가중 계산과 누락 데이터 계약을 구현한다.
- CCTV·비상벨 부분 지표와 공식 전체 점수를 구분한다. 가로등 미확보를 0점이나 만점으로 대체하지 않는다.
- 시설 비용이 후보 선택에 반영되도록 하고, 후보 병합·중복 제거·추가시간 상한을 적용한다.
- **완료 기준:** 계산 fixture와 실제 출발·도착 사례에서 지표·선택 이유·누락 상태를 재현 가능하게 검증.

### 5. 결과 화면·Room 즐겨찾기 마무리

- 구간별 취약 이유와 데이터 기준일·누락·평가 상태를 표시한다.
- Room에 허용된 사용자 지정 장소·자체 경로 정보와 버전을 저장하고 재시작·오프라인 조회·재평가를 검사한다.
- TMAP 반환값을 장기 보관할 항목은 공급자 조건을 확인한 뒤 정한다.
- **완료 기준:** 검색 → 비교 → 상세 → 저장 → 재조회 흐름과 오래된 결과 안내.

### 병행할 데이터·현장 작업

- 가로등 정상 자료·좌표·기준일·시흥 범위·이용조건 확보.
- CSV 원 다운로드 페이지와 재사용 조건 기록.
- 정왕역 실제 출구 연결, 교문 운영시간, 보도·횡단·육교·시설 접근성을 주·야간 조사.
- 검증한 연결만 근거와 버전을 붙여 그래프에 반영하고 재탐색.
- 첫 통합 경로를 검증한 뒤 시흥 전체로 그래프·시설·성능 범위 확대.
