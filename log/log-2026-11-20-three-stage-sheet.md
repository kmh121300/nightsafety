# 하단 경로 패널 숨김·요약·상세

작성일: 2026-11-20 · 최종 수정일: 2026-11-20 · 시간 기준: Asia/Seoul

## 후속 수정: 숨김 상태 복귀 손잡이 표시

사용자 피드백으로 숨김 상태의 투명 복귀 영역을 남색 배경/밝은 손잡이가 보이는48dp 바로 수정했다. 경로 내용은 숨기고 손잡이만 남기며 위로 스와이프/탭→요약, 다시 위로→상세 동작을 재사용한다. 지도 버튼/가시 영역 여백도 바 높이에 맞췄다. 새 APK 빌드/단위39개/lint 오류0·경고50, API35 일반 화면 전체 제스처 회귀·작은 화면 손잡이/스와이프 복귀 확인 통과. [최신 검증/캡처](../source/verification/three-stage-handle-2026-11-20/verification.md). 아래 투명 영역 검증은 당시 APK의 과거 기록이다.

사용자 승인으로 기존 하단 패널을 숨김→요약→상세 세 단계로 변경했다. [계획](../source/docs/superpowers/plans/2026-11-20-three-stage-sheet.md). Material BottomSheetBehavior 및 숨김일 때만 나타나는 투명48dp 복귀 영역을 사용한다. 상세→요약→숨김 순서, 하단 스와이프/접근성 클릭→요약, 요약의 스크롤 초기화 및 지도 버튼 여백 갱신을 적용했다. 상단 UI 문제·DB·점수 변경은 범위 밖이다.

## 2026-11-20 검증

Windows/JDK21.0.11/Gradle9.7.1, API35 emulator-5556. 기존 APK에서 숨김 실패를 확인하고 새 APK에서 일반/작은 화면 지정 제스처 회귀를 모두 통과했다. 설치 해시 일치, 숨김/요약/상세·빠른 하향 요약 정지·숨긴 상태 전체화면/복귀·복귀 영역 클릭 확인. 화면 설정 복원. 새 APK DB startup_snapshot verified=true와 검색/요약 표시 확인. 빌드·단위39개 통과, lint 오류0·경고50. 최종 APK SHA-256 및 캡처·명령·실패/성공 근거는 [검증 기록](../source/verification/three-stage-sheet-2026-11-20/verification.md)에 보존한다. 실기기/전체 인수·TalkBack 실제 사용은 미검증이다.
