## 2026-10-27 진행 중 관찰 이력

아래 목록은 작업 중 남긴 기록이다. 최종 완료 결과는 다음 절을 확인한다.

- 호스트 GPU의 전체 UI 검사는 첫 지도 준비 상태에서 시간 초과했다. 화면은 검정이었다.
- 전원 Awake/IsPowered/StayOn과 boot_completed=1, 앱 프로세스 존재를 확인했다. 앱을 벗어나 Android 홈을 캡처해도 검정이었다. 이 실행의 시험 환경 렌더링 이상을 앱/SDK 결함과 구분한다. 구체적인 드라이버 원인은 미확정이다.
- [날짜별 실패 기록](../source/verification/android-2026-10-26_235713_395139/failure.md)과 홈 비교 이미지를 보존했다.
- 기존 에뮬레이터의 화면 설정을 복원하고 종료했다. 원래 AVD 자료는 삭제하지 않고 TEMP의 새 데이터 이미지로 API35/소프트웨어 렌더링/메모리3072MB 환경을 시작했다. 홈 화면이 정상인지 먼저 확인할 계획이다.
- 새 임시 환경에서는 홈 화면이 표시됐지만 앱 실행 전부터 System UI 응답 없음 창이 발생했다. [앱 실행 전 캡처](../source/verification/android-r4-2026-10-27-home-systemui.png)를 보존했다. 검은 호스트 GPU 화면과 별개의 시스템 초기화 오류로 기록한다.
- 같은 새 APK로 새 임시 환경에서 TMAP 준비·시설511개와 기본 검색 후보3개 검사가 통과했다. 나머지 전체 UI 검사는 진행 중이며 아직 전체 통과로 표시하지 않는다.
- 실패 실행도 날짜·마지막 관찰 상태·완료한 단계만 새 failure.md로 남기도록 UI 도구를 보완했다. 새 회귀1개가 실패하는 것을 확인한 뒤 수정했고, 증거 보존 회귀는 총3개 통과했다. 앱 동작 코드는 변경하지 않았다.
- 구간 상세·주황 표시·시설511→241→511 필터와 Room 저장/프로세스 재시작/오프라인 복원이 실제 UI 검사에서 통과했다. 수정·최신 재조회·삭제는 진행 중이다. 주황 구간 캡처를 직접 시각 확인했다.

상태와 후속 검사는 [R4 검증 기록](../source/verification/android-r4-2026-10-26.md) 및 [전체 로드맵](../ROADMAP.md)을 갱신한다. 실기기 연결/GPS 검증은 아직 확보되지 않았다.
