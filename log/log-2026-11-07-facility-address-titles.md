# 시설 종류와 주소 표시

작성일: 2026-11-07 · 최종 수정일: 2026-11-07 · 시간 기준: Asia/Seoul

사용자가 CSV 행 번호 대신 시설 종류/주소 표시를 승인했다. 공통 Facility.title 생성부를 바꿔 묶음 목록/시설 목록/상세/native 명칭에 반영한다. 도로명 우선→지번→주소 정보 없음, 내부 식별 ID는 보존한다. CCTV/비상벨 앱 assets에서 주소가 빠져 있어 원본 공공 CSV의 헤더 포함 csv_row(첫 데이터2행), 좌표/기준일 일치를 검사한 후 주소2개 필드만 보완한다. 원본 CSV/과거 연구 산출물/DB/경로/점수/기록 수는 변경하지 않는다. 지정 회귀2개 먼저 추가, 검증 진행 중.

## 최종 결과

새 제목 회귀2개를 먼저 실행해 지정9개 중 새2개 ComparisonFailure를 확인했다. 도로명 우선/지번 fallback/주소 없는 경우·blank/null 무시·기존 name의 행 번호 숨김·내부 cctv:22 ID 유지·실제 첫 CCTV/비상벨 주소 포함을 검증했다. 공통 제목/상세 주소 helper를 구현하고 경찰 후보 시설명은 상세에 보존했다. 원본508개를 파일명/행/좌표/기준일로 전수 대조한 뒤 앱 assets 주소2필드만 추가했고, 해당 필드를 제거한 JSON이 이전과 같음을 확인했다. 원본 CSV 두 복사본 byte 일치/각 SHA256과 matched/with_address270+238을 기록했다. 보안등 주소는 기존 자료를 그대로 사용한다.

기존 audit_facilities.py exporter에 주소2컬럼을 보존하도록 추가하고 ast 문법 검사를 통과했다. 과거 연구 산출물/원본 CSV/DB는 변경하거나 재생성하지 않았다. 앱 자산 생성 시 같은 주소 보존 경로를 따른다.
